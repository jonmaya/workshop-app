# Project Documentation Context (Non-Obvious Only)

- All app code lives in `src/app/` — this is an App Router project with no `pages/` directory.
- `LayoutProps` and `PageProps` generic types are globally declared by Next.js in `.next/types/routes.d.ts` and `.next/dev/types/routes.d.ts` — they do not appear in any source file import.
- The managed `<!-- BEGIN:nextjs-agent-rules -->` block in `AGENTS.md` is auto-regenerated by `next dev` — it will reappear if removed without committing.
- There is no Tailwind config JS file; all theme customisation is in `src/app/globals.css`.
- No testing infrastructure exists in this project.

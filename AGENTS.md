## Stack

- **Next.js 16.3.1** (App Router) · **React 19.2.8** · **TypeScript 5** (strict mode)
- **Tailwind CSS v4** via `@tailwindcss/postcss` — configured with `@import "tailwindcss"` in CSS, NOT a `tailwind.config.js`
- **React Compiler** is enabled (`reactCompiler: true` in `next.config.ts`) — do not add manual `useMemo`/`useCallback` unless you have a specific reason
- No test framework is installed

## Commands

All commands must be run from `bob-workshop-app/`:

```bash
npm run dev      # start dev server (http://localhost:3000)
npm run build    # production build
npm run lint     # ESLint (eslint-config-next/core-web-vitals + typescript)
```

There are no tests.

## Non-Obvious Type Conventions

- `PageProps<'/route'>` and `LayoutProps<'/route'>` are **globally available** — they come from `.next/types/routes.d.ts` (auto-generated by Next.js build). Do not import them; use them directly.
  - `PageProps<R>` — `{ params: Promise<...>, searchParams: Promise<...> }`
  - `LayoutProps<R>` — `{ params: Promise<...>, children: React.ReactNode }`
  - Both `params` and `searchParams` are **Promises** — must `await` them (Next.js 15+ breaking change)

## Tailwind v4 Specifics

- CSS variables for colours/fonts are declared in `globals.css` under `@theme inline { … }` — this replaces the JS config file
- `globals.css` uses `@import "tailwindcss"` (not `@tailwind base/components/utilities` directives)

## Path Alias

`@/*` maps to `./src/*` — use for all non-relative imports within `src/`.
